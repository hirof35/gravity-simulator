TypeScript と HTML5 Canvas API を用いて作成された、ブラウザ上でリアルタイムに動く物理シミュレーターです。
自由落下、放物線運動、壁や地面との衝突（跳ね返り）といった物理現象を、速度ベクトルの変化とともに視覚的に理解することができます。

## 🚀 主な機能と特徴

- **リアルタイム物理シミュレーション:** 重力加速度が速度（$Y$ 方向）に与える影響を毎フレーム計算し、滑らかな放物線運動を再現。
- **速度ベクトルの可視化:** ボールから伸びる**赤い線（ベクトル矢印）**によって、現在の移動方向と速度の大きさがひと目で分かります。
- **動的なパラメータ調整:**
  - **重力 ($g$):** 値を大きくすると落下速度が急激に増し、`0` にすると無重力状態になります。
  - **反発係数 ($e$):** 地面や壁に衝突した際のエネルギー保存率（跳ね返り具合）を調整できます。
- **インタラクティブなUI:** スライダーによる直感的な操作と、ワンクリックで初期状態に戻せるリセットボタンを搭載。

📝 物理演算の仕組み（コードの解説）シミュレーターの核となる src/main.ts では、以下の物理数式をフレーム（毎秒約60回）ごとに計算しています。速度の更新 (重力加速度の加算):$$v_y = v_y + g$$位置の更新:$$x = x + v_x$$$$y = y + v_y$$衝突時の反発:地面に衝突した際、縦方向の速度（$v_y$）を反転させ、反発係数（$e$）を掛け合わせています。$$v_y = -v_y \times e$$
